Instant alerts

KickAlert listens to Kick's real-time connection, so the alert arrives when the stream starts, not minutes later. Pick a sound per channel, set quiet hours, or pause everything until morning.

Auto-launch

Choose the channels that should open by themselves. The stream opens in a new tab as soon as it starts, with no duplicate tabs, and the tab can close itself if a raid moves the stream elsewhere.

Know what happened

Raids, stream ends, category changes and moved streams can each have their own alert and their own sound, channel by channel.

Chat radar

Get a notification when your name or a word you chose shows up in up to 5 chats, even while Kick is closed. Chat filters hide spam and catch words written with look-alike letters.

    Questions

    Is KickAlert free?

    Yes. Every feature is free and there is no limit on how many channels you follow.

    Do I need to keep Kick open?

    No. KickAlert runs in the background and notifies you even when no Kick tab is open. You only need to be signed in to Kick in the same browser.

    I installed it but get no notifications.

    New installs start quiet so you are not flooded. Turn on the bell on the channels you want, or for all channels at once in Settings. The "Will this channel notify you?" check in each channel's settings shows anything else that could block an alert.

    Which browsers does it work in?

    Chrome and Firefox today, with Edge and Opera on the way. Brave, Vivaldi and other Chromium browsers can install it from the Chrome Web Store.
