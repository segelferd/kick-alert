KickAlert

Kickの配信通知が来ない・遅いときの原因と対処法

推しの配信が始まったのに通知が届かない、届いても数分遅れる。そんなときに確認したいポイントと、PCで見逃さずに通知を受け取る方法をまとめました。

まず確認したい5つのこと

  • 配信者をフォローしているか、チャンネルの通知がオンになっているか
  • ブラウザの通知が許可されているか（Chromeなら「設定 → プライバシーとセキュリティ → サイトの設定 → 通知」）
  • Windowsの「応答不可」「集中モード」やmacOSの「集中モード」で通知が止められていないか
  • スマホの場合、Kickアプリが省電力設定でバックグラウンドを制限されていないか
  • Kickのタブを開いているか（ブラウザの通知は、基本的にタブを開いていないと届きません）

Kickを開かずに通知を受け取るには

Kickのタブを開いておかなくても通知を受け取りたい場合は、ブラウザ拡張機能を使う方法があります。KickAlertは、フォロー中のチャンネルが配信を始めた瞬間にデスクトップ通知を出す、無料の拡張機能です（Chrome / Firefox）。

  1. Chromeウェブストア、またはFirefox Add-onsからKickAlertを追加します。
  2. 同じブラウザでKickにログインし、KickAlertのアイコンをクリックすると、フォロー中のチャンネルが表示されます。
  3. 通知を受け取りたいチャンネルのベルをオンにします（インストール直後は通知がオフになっています）。

それでも通知が来ないとき

KickAlertの各チャンネル設定にある「このチャンネルの通知は届きますか？」を押すと、通知を止めている可能性のある項目（ブラウザの許可、チャンネルの通知モード、一時停止、おやすみ時間、フィルター、Kickとの接続）をその場で確認できます。
